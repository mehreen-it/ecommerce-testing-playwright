E-Commerce Testing Project - Manual, API & Automation Testing

Quality Assurance Testing Project
A comprehensive software testing project demonstrating manual testing, API validation, and end-to-end automation testing for an e-commerce web application using Playwright, Postman, and JavaScript.

📖 Overview

This repository contains a complete Quality Assurance testing project carried out on the Demo Web Shop e-commerce application.

The project focuses on validating critical customer workflows through manual testing, API testing, and automated end-to-end testing. Core user journeys such as product browsing, shopping cart management, user registration, and checkout were thoroughly tested to ensure the application behaved reliably under normal user conditions.

Throughout the project, I created detailed manual test cases, validated backend APIs using Postman, and automated regression scenarios using Playwright. The project demonstrates a practical approach to software testing while applying industry-standard QA practices.

🧪 Testing Performed
Manual Testing

Manual test cases were created to validate key e-commerce functionality, including:

Product browsing
Adding items to the shopping cart
Viewing cart contents
Removing products from the cart
User registration
Registered user checkout

Each test case includes:

Test steps
Expected results
Actual results
Pass/Fail status
Supporting screenshots
API Testing

The application's APIs were validated using Postman to verify:

GET requests for retrieving product data
POST requests for shopping cart operations
Status codes
Response body validation
JSON response structure
API reliability

Testing confirmed that backend endpoints behaved correctly and returned the expected data.

Automation Testing

Playwright automation scripts were created to automate critical user workflows, including:

Adding products to the cart
Validating shopping cart contents
Removing products from the cart

The automation helped improve regression testing by providing consistent, repeatable validation of key application functionality.
